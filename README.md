# Codificação Back-End

## 📚 Sobre a disciplina

A disciplina de **Codificação Back-End** apresenta os principais conceitos e práticas utilizados no desenvolvimento da parte de trás de aplicações web. Durante as aulas, são estudados temas relacionados à programação, servidores, bancos de dados, APIs e integração entre sistemas.

## 🎯 Objetivos

* Compreender os fundamentos do desenvolvimento Back-End;
* Aprender a criar e organizar aplicações do lado do servidor;
* Conhecer conceitos de APIs e requisições HTTP;
* Trabalhar com bancos de dados;
* Desenvolver boas práticas de programação;
* Utilizar ferramentas de versionamento, como o Git e o GitHub.

## 💻 Conteúdos da aula

Nesta aula, foram abordados conceitos fundamentais de Back-End, incluindo:

* Introdução ao desenvolvimento Back-End;
* Funcionamento de servidores;
* Requisições e respostas HTTP;
* Estrutura de uma aplicação web;
* APIs;
* Banco de dados;
* Versionamento de código com Git e GitHub.

## 🛠️ Tecnologias e ferramentas

As principais ferramentas utilizadas ou estudadas na disciplina incluem:

* Git
* GitHub
* HTML
* CSS
* JavaScript
* Node.js
* Banco de dados
* APIs REST
